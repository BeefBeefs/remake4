# Akuma – Demon Spawn (Lamentation Sword) remake

TypeScript + three.js web port of the 1999 PC action RPG by JC Research / Triger Soft (abandonware).
Work in progress: see `PROGRESS.md` and `docs/FORMATS.md`.

Controls: WASD/arrows or click to move, space / right click attack, 1-3 switch hero. Use the top bar to pick a map or to
talk to a scripted NPC of the current map. URL: `#t1` (map id), `?flip=1` mirrors the side-facing sprites.

`npm install && npm run dev`. Game data is converted from the original disc by `tools/build_assets.py`.
